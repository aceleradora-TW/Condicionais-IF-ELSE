# maiorEMenorEntreQuatro
Enunciado:
 Crie uma função chamada maiorEMenorEntreQuatro que receba quatro números inteiros. A função deve identificar o maior e o menor valor entre os quatro.
O que você deve fazer:
Receber quatro números inteiros como entrada.
Comparar os quatro valores para encontrar:
O maior entre eles.
O menor entre eles.
Retornar ambos os valores.
Exemplos:
maiorEMenorEntreQuatro(1, 2, 3, 4);
Entrada: 1, 2, 3, 4 → Saída: "Maior: 4, Menor: 1"
maiorEMenorEntreQuatro(-1, 0, -10, 20);
Entrada: -1, 0, -10, 20 → Saída: "Maior: 20, Menor: -10"
