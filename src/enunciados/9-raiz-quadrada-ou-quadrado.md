# calcularRaizOuQuadrado
Enunciado:
 Crie uma função chamada calcularRaizOuQuadrado que receba um número inteiro. A função deve verificar o valor do número e executar uma das operações:
Se o número for maior ou igual a 0, a função deve calcular e retornar a raiz quadrada exata (raiz quadrada perfeita) do número.
Se o número for menor que 0, a função deve calcular e retornar o quadrado desse número.
Exemplos:
calcularRaizOuQuadrado(16);
Entrada: 16 → Saída: 4 (porque 4 × 4 = 16)
calcularRaizOuQuadrado(25);
Entrada: 25 → Saída: 5 (porque 5 × 5 = 25)
calcularRaizOuQuadrado(18);
Entrada: 18 → Saída: "Não possui raiz quadrada exata"
calcularRaizOuQuadrado(-3);
Entrada: -3 → Saída: 9 (porque -3 × -3 = 9)
calcularRaizOuQuadrado(0);
Entrada: 0 → Saída: 0 (porque 0 × 0 = 0)
