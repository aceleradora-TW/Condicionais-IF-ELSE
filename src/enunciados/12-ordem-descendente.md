# ordenarDescendente
Enunciado:
Crie uma função chamada ordenarDescendente que receba três números inteiros. A função deve retornar os três valores em ordem decrescente.
Exemplos:
ordenarDescendente(3, 1, 2);
Entrada: 3, 1, 2 → Saída: "3, 2, 1"
ordenarDescendente(5, 8, 2);
Entrada: 5, 8, 2 → Saída: "8, 5, 2"
