# ordenarAscendente
Enunciado:
Crie uma função chamada ordenarAscendente que receba três números inteiros. A função deve retornar os três valores em ordem crescente.
Exemplos:
ordenarAscendente(3, 1, 2);
Entrada: 3, 1, 2 → Saída: "1, 2, 3"
 ordenarAscendente(7, 7, 7);
Entrada: 7, 7, 7 → Saída: "7, 7, 7"
