# calcularVenda
Enunciado:
 Crie uma função chamada calcularVenda que receba o valor unitário de um produto e a quantidade vendida. A função deve calcular o valor total da venda e retornar uma mensagem com o resultado. Se o total ultrapassar R$100,00, a mensagem deve incluir a frase: "Bonificação de 10% para o vendedor!".
Exemplos:
calcularVenda(20, 6);
Entrada: valorUnitario = 20, quantidade = 6 → Saída: "Valor total: R$120. Bonificação de 10% para o vendedor!"
calcularVenda(15, 4);
Entrada: valorUnitario = 15, quantidade = 4 → Saída: "Valor total: R$60."
