# verificarEmprestimo
Enunciado:
Crie uma função chamada verificarEmprestimo que receba dois valores: o salarioBruto e o valorPrestacao. A função deve verificar se a prestação é menor ou igual a 30% do salário. Se for, o empréstimo pode ser concedido (retorne true). Caso contrário, o empréstimo deve ser negado (retorne false).
Exemplos:
verificarEmprestimo(3000, 900);
Entrada: 3000 e 900 → Saída: true
verificarEmprestimo(4000, 1500);
Entrada: 4000 e 1500 → Saída: false
